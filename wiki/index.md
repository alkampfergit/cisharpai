## What is Cisharpai?

Cisharpai is a unified .NET client library that provides a single interface for chat completions across multiple LLM providers (OpenAI, Azure OpenAI, and Anthropic). You can swap providers with minimal code changes by keeping your application code focused on the shared abstractions.
