## What is Cisharpai?

Cisharpai is a unified .NET client library that provides a single interface for chat completions and embeddings across multiple LLM providers (OpenAI, Azure OpenAI, Anthropic, and Cohere). You can swap providers with minimal code changes by keeping your application code focused on the shared abstractions.
